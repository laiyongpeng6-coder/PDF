# PDF 扫描器 / 下载器 竞品功能调研报告

> 调研时间：2026-06-08
> 调研目标：梳理当前主流的 PDF 扫描器、PDF 工具箱以及"网页/网盘 → PDF"下载类 App，归纳主流功能集，作为我们自己的 Android PDF 扫描/下载 App 的功能规划依据。
> 报告类型：市场 + 产品功能调研
> 适用对象：产品 / 设计 / Android 开发同学

---

## 0. 摘要 TL;DR

如果只能抄一份"2025 主流必备功能清单"，那就是下面这 25 条。我们做新 App 时建议**先做 MVP（约 12 条），再按阶段补齐**。

**MVP（建议优先做）**：

1. 拍照 / 相册选图 → 智能识别文档边缘 + 透视矫正
2. 多页连续扫描、合并为单个 PDF
3. 多种输出模式：原始 / 增强 / 灰度 / 黑白 / 增强去阴影
4. 输出格式：PDF / JPG（PNG 可选）
5. 多场景扫描：文档 / 证件 / 发票 / 白板 / 书籍 / 名片
6. 多语言 OCR（中英日韩，扫描件可搜索、可复制）
7. 表格还原（合并单元格 + 边框识别）
8. 公式识别（数学/化学公式 → LaTeX 或图片）
9. PDF 阅读 + 标注（高亮、下划线、文本框、涂鸦）
10. PDF 基础编辑：合并、拆分、删除页面、旋转、调整顺序
11. PDF ↔ Word / Excel / PPT / 图片 互转
12. 文档管理：文件夹 / 标签 / 搜索（按文件名、OCR 文本、日期）

**进阶（差异化亮点）**：

13. 试卷 / 笔记"去手写" → 还原空白件
14. 拍证件照（抠图换底、智能美颜、多规格）
15. 拍照翻译（多语种互译 + 例句）
16. 屏幕/课件记录（去摩尔纹、提取重点）
17. 网页/链接 → PDF（内置浏览器、参数自定义）
18. 网盘文件下载与离线保存（百度网盘、阿里云盘、OneDrive、Google Drive、Dropbox、夸克网盘、腾讯微云等）
19. 分享到微信/QQ/邮件/链接（二维码 / 短链 / 限制有效期）
20. 多人实时协作（评论、@、版本回溯）
21. AI 鉴伪 / 真伪检测（扫描件的 PS 检测、合同水印检测）
22. 电子签名 + 手写签名 + 数字证书签名
23. PDF 加密（密码、权限）、加水印（文字 / 图片）、权限控制（禁止复制/打印）
24. 团队 / 企业空间、角色权限、审计日志
25. 智能助手：合同关键信息抽取（金额、甲方乙方、日期）、发票自动归类、表格问答

> 后文是详细竞品矩阵和功能拆解。

## 1. 调研范围

按产品形态，把竞品分成 4 大类：

| 类别 | 代表产品 |
|------|----------|
| **专业扫描 App** | Adobe Scan、扫描全能王 CamScanner、Genius Scan、白描、夸克扫描王、扫描王 Pro、SwiftScan、MobiScan |
| **网盘内置扫描** | 百度网盘、夸克（App 内）、腾讯文件、阿里云盘、Google Drive |
| **PDF 工具箱 / 阅读器** | Adobe Acrobat Reader、Foxit、Xodo、WPS Office、PDFgear、PDFelement |
| **网页 / 链接 → PDF 下载类** | Web to PDF、Convert web to PDF、URLToPDF、Website to PDF、Web to PDF saver |
| **生态派** | Microsoft Lens（→ OneNote/Word/PPT）、Apple Notes（系统级）、iPhone Files |

> 用户原话"PDF 扫描器/下载器"，**下载器**我理解为两个维度：(a) 把外部来源（网页、网盘链接、聊天里的 PDF）拉下来保存到本地；(b) 把扫描/导入的内容保存/导出成 PDF。两个角度我们都会覆盖。

## 2. 重点竞品速览

### 2.1 Adobe Scan（国际综合最强）

**定位**：免费 + Pro 订阅，全球最知名的扫描 App 之一。

| 维度 | 功能 |
|------|------|
| 扫描 | 自动边界检测、透视矫正、阴影/反光去除、AI 增强；支持文档/表单/名片/白板/手写 |
| OCR | 内置 Adobe Sensei OCR；扫描件可编辑、可搜索；可匹配字体重新输入文本 |
| 编辑 | 标记/绘图/形状/注释；与 Acrobat Pro 互通后可做表单填写、合并、密码保护 |
| 转换 | PDF、JPEG、Word（Pro） |
| 协作 | 链接/邮件分享；上传到 Dropbox、Google Drive；跨设备同步批注；多人审阅 |
| 云 | Adobe Document Cloud；iOS/Android/Web/桌面 |
| 安全 | Pro 密码保护、加密传输与存储 |
| 平台 | iOS 15+ / Android 8+ |
| 商业模式 | 核心免费，高级功能需 Acrobat Pro 订阅 |

**对标我们的启示**：扫描体验（AI 增强、边缘检测、阴影去除）是**基线**，OCR + 跨端同步是**必须**。

### 2.2 扫描全能王 CamScanner（中国市场份额第一）

**定位**：3 亿用户，文档处理全链路（扫描→识别→编辑→转换→管理→分享）。

| 维度 | 功能 |
|------|------|
| 扫描 | 自动切边 / 多种滤镜 / 书籍模式 / 证件 / 拍证件照 / 拍图识字 |
| OCR | 41 种语言识别、长文一键提取、可搜索、可复制；**AI 图片鉴伪/反 PS 检测** |
| 编辑 | 合并 / 拆分 / 提取 / 删除页面 / 调序 / 旋转 |
| 转换 | PDF ↔ Word/Excel/PPT/JPG，**版面还原 + 表格还原** |
| 协作 | 微信 / QQ / 邮件 / 传真（覆盖 30+ 国家和地区）/ 无线打印 |
| 安全 | PDF 签名 / 水印 / 加密 |
| 翻译 | 智能翻译 |
| 商业 | 免费 + 高级会员 + SVIP |

**对标我们的启示**：**表格还原**是核心差异化点（中国教育/办公刚需）；**反 PS/AI 鉴伪**是新趋势；**本地化分享渠道（微信、QQ、传真）**不能少。

### 2.3 夸克扫描王（阿里系，主打"学习"）

**定位**：夸克 App 拆出的独立扫描品牌，主打学生/教育场景。

| 维度 | 功能 |
|------|------|
| 扫描 | 文件 / 证件 / 发票 / 书籍 / 绘画 / 电子屏幕（去摩尔纹） |
| OCR | 文字提取 + 排版还原 + 在线编辑 |
| PDF | 阅读 / 编辑 / 分割 / 合并 / 压缩 / 转 Word / 在线签名 |
| 特色 | **试卷去手写**（还原空白）、拍照翻译（带例句）、屏幕/课件记录（去摩尔纹 + 提取重点） |
| 证件照 | 自拍抠图换底、智能美颜、多规格 |
| 跨端 | 手机 / PC Web（scan.quark.cn）/ 微信小程序 三端互通 |
| 商业 | 7 天免费 + 自动续费（约 98 元/季度），差评集中在"隐藏扣费" |

**对标我们的启示**：**去手写**是 2024-2025 教育赛道刚需；**屏幕/课件记录**（去摩尔纹 + 提取重点）比纯截图好用；**三端互通**是趋势；**自动续费提示要清楚**（差评重灾区）。

### 2.4 Microsoft Lens（前 Office Lens）

**定位**：微软官方，免费，无内购，Microsoft 365 生态入口。

| 维度 | 功能 |
|------|------|
| 扫描 | 文档 / 白板 / 名片 / 收据 / 照片 |
| 模式 | 白板优化、名片 OCR（自动归档联系人） |
| 转换 | 直接导出 PDF / Word / PowerPoint / Excel / OneNote |
| 协作 | 与 OneDrive / OneNote / Outlook / Office 全家桶无缝衔接 |
| 商业 | 完全免费 |

**对标我们的启示**：免费的"扫描 → 生态分发"是有效路径，**导出目的地**（Word/PPT/OneNote）的多样性比"扫描本身"更能黏住用户。

### 2.5 Genius Scan（隐私 + 离线）

**定位**：欧洲血统，强调 100% 离线、隐私优先、SDK 商业化成熟。

| 维度 | 功能 |
|------|------|
| 扫描 | 自动检测 + 透视校正 + 色彩增强 |
| PDF | 页面管理（增删调序、合并）+ 文字层（OCR 索引） |
| 分享 | 支持所有主流云存储（Dropbox / Drive / OneDrive） |
| 管理 | 标签分组 + 关键词搜索 + Genius Cloud 备份 |
| 场景 | 远程办公、差旅报销、课堂作业、乐谱/画作高分辨率 |
| 商业 | 订阅制 + 企业 SDK |

**对标我们的启示**：**离线 + 隐私**是企业市场的卖点；**高分辨率扫描**（乐谱、画作）是垂直场景的差异化。

### 2.6 白描（OCR 极简派）

| 维度 | 功能 |
|------|------|
| 核心 | OCR 文字识别 + 表格识别 + 公式识别 + PDF 转 Word + 横竖排识别 |
| 体验 | 极简、专注 OCR；16 种语言；批量识别高效 |
| 场景 | 文字工作者、研究者、网页/截图文字提取 |
| 商业 | 基础免费，Pro 约 12-18 元**买断**（不订阅，性价比高） |

**对标我们的启示**：**公式识别**是中国 K12 场景刚需（数学/物理/化学）；**买断制**在国内有用户基础（不想被订阅割）。

### 2.7 腾讯文件 / 腾讯文档扫描王

| 维度 | 功能 |
|------|------|
| 核心 | 高清扫描 + OCR + PDF 转换 + 文档管理 + 微信/QQ 文件互通 |
| 特色 | 与微信/QQ 深度集成、批量扫描、文档分类、中英双语 OCR |
| 商业 | 基础免费，高级功能（去水印/批量）需会员 |

**对标我们的启示**：和微信/QQ 互通是腾讯系护城河，我们没有这层关系，**需要替代方案**（比如分享到任意 App + 二维码 / 短链）。

### 2.8 百度网盘（云 + 扫描二合一）

| 维度 | 功能 |
|------|------|
| 核心 | 文档扫描 + OCR + PDF ↔ Word/Excel + 自动备份网盘 |
| 特色 | 扫描件直存云端、大文件存档 + 分享、AI 手写识别 |
| 商业 | 基础扫描免费，大容量云存储 + 高级功能需会员 |

**对标我们的启示**：**"扫描即上传"**是强需求，但**不能完全依赖第三方网盘**（要支持多种云端目的地）。

### 2.9 PDF 阅读器 / 工具箱（Adobe Acrobat Reader / Foxit / Xodo / WPS）

| 维度 | Adobe Acrobat Reader | Foxit | Xodo | WPS |
|------|----------------------|-------|------|-----|
| AI | **Liquid Mode**（自适应手机阅读） | ❌ | ❌ | ❌ |
| 阅读 | 暗黑模式、单页/连续滚动、自由缩放、强力搜索 | 快速启动、调节背景亮度 | 夜间模式、高倍缩放 | 跳页、书签、注释、搜索 |
| 编辑 | 付费：高亮/批注/OCR/导出 | 注释/笔记/分享 | 页面管理/合并/注释/书签 | 阅读/编辑/转换/合并/水印 |
| 云 | Adobe 云 | Drive / OneDrive / Dropbox | Drive / OneDrive / Dropbox | **1GB 免费** + 多家第三方 |
| 形式转换 | PDF 为主 | PDF 为主 | PDF 为主 | **Word/PPT/Excel ↔ PDF** |
| 商业 | 免费 + 内购订阅 | 免费 + 高级 | **完全免费** | 免费 |
| 场景 | 重度专业 | 轻量快速 | 不想付费 | 办公 + PDF 一体化 |

**对标我们的启示**：**"PDF 阅读体验"**（暗黑模式、缩放、搜索、夜间模式）是基础；**Liquid Mode 这种 AI 自适应排版** 是加分项；WPS 那种"办公 + PDF 一体化"在中国用户基数大。

### 2.10 网页 / 链接 → PDF 下载类（小众但用户画像明确）

| App | 链接转 PDF | 内置浏览器 | 参数自定义 | 离线阅读 | 网盘分享 |
|-----|:---------:|:---------:|:---------:|:-------:|:-------:|
| Web to PDF | ✅ | ✅ | ❌ | ✅ | ✅ |
| Convert web to PDF | ✅ | ❌ | ✅ | ✅ | ✅ |
| Website to PDF | ✅ | — | ✅ | ✅ | ❌ |
| Web to PDF saver | ✅ | — | ❌ | ✅ | ❌ |
| URLToPDF | ✅ | — | ✅ | ✅ | ✅ |

**对标我们的启示**：**内置浏览器** + **链接转 PDF** 是个低成本高感知的功能；可以做"扫码/粘贴链接/从分享菜单接收链接 → 转 PDF → 直接存到云端"。

## 4. 关键洞察

### 4.1 必须做的（不做就没用户）

- **AI 增强扫描**（自动边检 + 透视 + 阴影）是基线，**用户不需要点任何按钮**就要把图修好。
- **OCR 至少支持中英文**；扫描后要能搜索、能复制。
- **多页合并 + 多种输出格式**（PDF/JPG）。
- **微信/QQ 分享**是中文 Android 的"水电煤"，不做就输一半。
- **PDF 基础编辑**（合并/拆分/旋转/删页）几乎是必装。
- **暗黑模式 + 8dp 网格 + 大字号**是阅读类 App 的基本礼仪。

### 4.2 能拉开差距的（差异化点）

- **去手写 / 试卷还原**（夸克已验证）
- **公式识别**（白描已验证，学生刚需）
- **表格还原**（CamScanner 已验证，办公刚需）
- **AI 鉴伪 / 反 PS**（CamScanner 新功能，保险/法务场景）
- **链接/网页 → PDF**（小众但缺）
- **多云盘目的地**（不是绑死某一家）
- **离线 + 隐私**（企业/Gov 客户强需求）

### 4.3 谨慎做的（高成本低收益 / 容易踩雷）

- **多人实时协作**（自研成本极高，要么接第三方，要么先不做）
- **传真**（CamScanner 优势，需要第三方合作才能做，单独做 ROI 低）
- **企业版 / SDK**（需要长期投入，可以放到后期）
- **AI 鉴伪**（法律风险，需要严肃标注"辅助参考，不作为法律依据"）

### 4.4 中国 vs 海外的差异

| 维度 | 中国 | 海外 |
|------|------|------|
| 分享渠道 | 微信 / QQ / 钉钉 / 飞书 | Mail / Slack / Teams |
| 云存储 | 百度网盘 / 夸克云 / 微云 / 阿里云盘 | Drive / Dropbox / OneDrive / iCloud |
| 隐私敏感度 | 中（更关心是否免费） | 高（Genius Scan 这种离线 App 很受欢迎） |
| 订阅付费 | 容易踩雷（夸克差评），**自动续费提示要清楚** | 习惯良好，Adobe / CamScanner Pro 都行 |
| 翻译 | 中英日韩刚需 | 多语种刚需 |
| 公式/去手写 | K12 强需求 | 低 |
| 拍照翻译 | 强需求 | 中 |
| 表格还原 | 强需求（财务、合同） | 中 |

## 5. 给我们的功能建议（分级路线图）

### Phase 1 - MVP（建议 8-10 周）

**目标**：做出一款"扫得清楚、转得准确、能分享、能管理"的 App，先拿下个人用户。

| 模块 | 功能 |
|------|------|

## 6. 商业模式建议

参考竞品定价（2025 公开数据）：

| 产品 | 免费策略 | 付费价位 |
|------|----------|----------|
| CamScanner | 含广告、限制 OCR 次数、加水印 | VIP ~25 元/月，SVIP 更贵 |
| 夸克扫描王 | 7 天试用 | ~98 元/季度（**差评多**） |
| 微软 Lens | 完全免费无内购 | — |
| 白描 | 基础功能免费 | 买断 12-18 元 |
| Adobe Scan | 核心免费 | Pro 订阅 ~50 元/月 |
| Genius Scan | 基础免费 | 订阅制 |
| WPS | 弹窗广告 + 部分功能 | 会员制 |
| Xodo | **完全免费无内购** | — |

**给我们的建议**：

1. **国内**：免费 + 会员订阅。**自动续费一定要在订阅页显著提示**（夸克的差评就是反面教材）。
2. **海外**：可以加买断（一次性解锁 Pro）以吸引不愿订阅的用户。
3. **避免广告弹窗**，影响"工具型"App 的专业感。
4. 留好**企业版 / 团队版**的接口，2B 客单价高、付费意愿强。

## 7. 风险清单

| 风险 | 应对 |
|------|------|
| OCR/转换 SDK 版权 | 优先 ML Kit（自有）+ Aspose/ComPDF（采购），不要直接用开源 iText 做商业闭源发布 |
| 隐私合规 | 中国《个人信息保护法》、欧盟 GDPR、加州 CCPA：扫描件默认本地；上传云端需明确同意 |
| 自动续费合规 | 工信部要求**主动告知、随时退订、提前 24h 提醒**；不要用 7 天"免费试用"陷阱 |
| 第三方网盘接口 | 百度 / 夸克 / 阿里云盘接口变化频繁，**做好 abstraction 层**，一个云盘挂了不影响其他 |
| 公式识别准确率 | 不达标就**降级为"图内可复制公式 LaTeX"**，不要强求"可编辑公式" |
| 表格还原 | 准确率 70% 是行业上限，要给用户**人工修正入口** |
| 商业 SDK 价格 | OCR/转换按页收费，**预估 DAU 后做成本测算**，否则后期涨价会很难 |
