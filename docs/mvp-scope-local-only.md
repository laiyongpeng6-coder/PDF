# 功能本地化筛选矩阵（v0.1）

> 原则：**任何依赖网络 / 第三方账户 / 付费 SDK 才能用的功能，全部从 v0.1 移除**。
> 允许的依赖：
> - 设备本地能力（CameraX、ML Kit on-device、SQLite/Room、本地文件系统）
> - 免费 / Apache-2.0 / LGPL 且可静态链接的开源库
> - Google Play 服务内置的 ML Kit（on-device 模式，不需要联网）
>
> 移除规则（满足任一即砍）：
> 1. **必须联网**（云 OCR、云转换、网盘 API、链接抓取）
> 2. **必须付费 SDK**（Aspose、ComPDF、Foxit SDK、Adobe Sensei 云端版）
> 3. **必须登录 / 第三方账号**（微信/QQ/OneDrive/Dropbox/Adobe ID/钉钉/飞书）
> 4. **合规风险大**（传真、鉴伪、企业审计）
> 5. **工程量超出 v0.1**（多人协作、AI 翻译、公式识别、试卷去手写准确率未达可用）

## v0.1 不做的非功能项

为了"100% 本地"，v0.1 主动放弃：

- **账号系统**（不登录、不注册）
- **云端同步**（不接任何网盘 / 账户）
- **崩溃数据上传**（v0.1 写本地日志文件，v0.2 评估后再说）
- **远程配置**（不接 Firebase Remote Config / 友盟 PUSH）
- **埋点 / 统计 SDK**（不接友盟 / GrowingIO / 神策 / Sensors）

> 这些都"非本地"，即使免费也**先不上**，等用户主动要"看数据"再单独评估。

## 法务提示（先讲清楚）

1. **iText 7 是 AGPL-3**：商业闭源 App 不能静态链接 iText（除非你也 AGPL）。**v0.1 一律用 PdfBox-Android**。
2. **ML Kit on-device**：免费、本地，但模型需 Play 服务下载（首次启动约几十 MB）。
3. **OpenCV Android**：Apache-2.0，可放心用。
4. **Bouncy Castle**：MIT-like，可商用。
