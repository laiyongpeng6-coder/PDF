## 5. 已知问题（v0.1.0）

### 5.1 编译相关

1. **JDK 21 必须**：AGP 9.2.1 不支持 JDK 17，**用户本机必须有 JDK 21**。
2. **OpenCV / PdfBox / ML Kit 首次构建下载**：约 60 MB。
3. **沙箱无法验证**：当前沙箱无 JDK，**`assembleDebug` 未跑过**；用户首次构建可能遇到小问题（已在 BUILD.md 列出 5 个常见错误的修复方法）。

### 5.2 运行时已知

1. **OCR 准确性**：中文场景下 ML Kit 准确率约 90%；手写体低很多。
2. **链接 → PDF 复杂页面**：SPA 渲染可能不完整；文档已说明。
3. **OpenCV 在老 GPU 上较慢**：边检 + 透视 + 滤镜 链式处理在低端机（< 4 核）可能 2-3 秒。
4. **i18n 切换 v0.1 走 Android 系统语言**：设置页 UI 已写但未应用（v0.2 用 `AppCompatDelegate.setApplicationLocales`）。

### 5.3 设计取舍

1. **没做"PDF 文本框标注"**：v0.1 只做高亮 + 涂鸦，文本框 v0.2。
2. **没做"插入空白页"**：v0.1 不支持。
3. **签名是透明 PNG 叠加**，不是 PKCS#7 数字证书签名。
4. **加密 PDF 改了 owner 密码后，需要 PdfRenderer 重新加载**：已用 renderEngine.close() 处理。
