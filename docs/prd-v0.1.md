## 0. 一句话定位

> **一款完全离线工作的 Android PDF 工具：把纸质文件 / 屏幕 / 链接，离线变成可搜索、可分享、可管理的 PDF，全部留在本机。**

> 跟扫描全能王 / 夸克的本质区别：**不联网、不传服务器、不登录、不要钱、没有广告**。每一份扫描件、每一个标签、每一条笔记、每一份签名，都在你手机的私有目录里。

## 1. 目标用户与场景

### 1.1 用户画像

- **学生 / 教师**：扫书、扫笔记、扫试卷（v0.1 不做去手写，但能扫描 + 归档 + 搜索）
- **律师 / 财会 / 政府工作人员**：对隐私敏感，不希望合同 / 票据 / 证件上传到任何服务器
- **商务 / 销售**：出差路上没有 WiFi，也能签合同、加水印、加密导出
- **技术爱好者 / 极简主义者**：拒绝一切"为用个工具非要注册账号"的 App
- **海外用户**：希望一次性买断、不要订阅（v0.1 之后再说）

### 1.2 场景剧本

| 场景 | 描述 |
|------|------|
| 教室 | 上课把白板拍下来 → 合并成 PDF → 标注重点 → 晚上回宿舍用全文搜索复习 |
| 差旅 | 在高铁上把纸质合同拍照扫描 → 加手写签名 → 设密码 → 分享到邮箱 |
| 报销 | 把一叠发票全部拍下来 → 多页合并 → OCR 全文 → 之后按"日期"或"金额关键词"搜出来 |
| 资料整理 | 收到一个 PDF 链接 → 粘贴到 App → 离线渲染存成本地 PDF → 离线阅读 |
| 法务 | 客户合同要保密 → 扫描后加文字水印 + 密码保护 → 只在本机查看 |

## 3. 页面流（信息架构）

```
┌─────────────────────────────────────────────┐
│                    首页（Documents）           │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  │
│  │ 📷 扫描   │  │ 🔗 链接  │  │ 📁 文件  │  │
│  └──────────┘  └──────────┘  └──────────┘  │
│                                              │
│  最近文档                                     │
│  ├─ 合同_2024.pdf        2小时前   [分享][⋯] │
│  ├─ 笔记_课堂.pdf        昨天      [分享][⋯] │
│  └─ ...                                      │
│                                              │
│  底部导航：文档 / 工具 / 设置                  │
└─────────────────────────────────────────────┘
```

### 3.1 页面清单

| # | 页面 | 主要交互 |
|---|------|---------|
| P1 | 启动页 | 仅展示 logo / 首次启动引导 + OCR 模型下载（一次性） |
| P2 | 文档首页 | 文档列表（缩略图 + 文件名 + 日期 + 标签），顶部搜索框 |
| P3 | 拍照扫描页 | CameraX 实时预览 + 自动捕获按钮 + 滤镜 / 场景切换 |
| P4 | 扫描结果编辑页 | 多页缩略图条 + 单页编辑（裁剪 / 旋转 / 滤镜） |
| P5 | 扫描后保存对话框 | 文件名 / 标签 / 存为 PDF 还是 JPG / 是否开启 OCR / 是否加密 / 是否加水印 |
| P6 | 链接输入页 | 文本框 + 历史 URL 列表 + 渲染进度 |
| P7 | 链接渲染预览页 | WebView + 工具栏（截整页 / 选区域 / 取消） |
| P8 | PDF 阅读页 | 全屏阅读 + 工具栏（搜索 / 目录 / 标注 / 分享 / 编辑） |
| P9 | PDF 编辑页 | 多页缩略图 + 操作菜单（合并 / 拆分 / 旋转 / 删页 / 调序 / 加密 / 水印 / 签名） |
| P10 | 标注页 | 高亮 / 涂鸦 / 手写签名 / 文本框（v0.2） |
| P11 | 工具页 | 入口列表：合并 / 拆分 / JPG↔PDF / 链接→PDF / 加密 / 水印 |
| P12 | 设置页 | 主题 / 默认滤镜 / OCR 语言 / 缓存清理 / 关于（**无账号、无同步、无订阅**） |

### 3.2 关键流程

#### 流程 1：扫描 → OCR → 加密 → 分享

```
P2 首页 → 点 📷
   → P3 拍照（自动捕获 ≥1 张）
   → P4 编辑（裁剪 / 旋转 / 滤镜）
   → P5 保存对话框
        ├─ 文件名：默认 "Scan_20260608_225930"
        ├─ 标签：可新建 / 多选
        ├─ 格式：PDF（默认） / JPG
        ├─ OCR：开（默认） / 关
        ├─ 加密：关（默认） / 开 → 弹密码输入
        └─ 水印：关（默认） / 开 → 选文字或图片
   → 后台异步：图像处理 → OCR → 生成 PDF → 写 Room 索引
   → 回到 P2，列表刷新，新文档在最前
   → 点 ⋯ → 系统分享
```

#### 流程 2：链接 → PDF

```
P2 首页 → 点 🔗
   → P6 粘贴 URL（或点历史记录）
   → 启动 App 内 WebView 加载（**完全本地**，不进系统浏览器）
   → P7 加载完成后显示预览 + 工具栏
        ├─ 截整页 → 弹文件名 / 标签 / OCR 开关
        └─ 取消
   → 保存
```

#### 流程 3：阅读 + 标注 + 分享

```
P2 首页 → 点某份 PDF
   → P8 阅读
   → 工具栏 → 搜索 → 输入关键词 → 命中位置高亮跳转
   → 工具栏 → 标注
        → P10 选 高亮 / 涂鸦 / 签名
        → 标注保存到 PDF（追加内容，不改原图）
   → 工具栏 → 分享 → 系统 Intent
```

#### 流程 4：管理

```
P2 首页 → 长按某份 PDF
   → 多选模式：批量分享 / 批量删除 / 批量打标签 / 批量加密
   → 顶部搜索框 → 文件名 / 标签 / OCR 文本 → FTS 命中
```

## 4. 数据模型（Room）

```kotlin
@Entity(tableName = "documents")
data class Document(
    @PrimaryKey val id: String,                  // UUID
    val name: String,                            // 文件名（含扩展名）
    val mimeType: String,                        // "application/pdf" | "image/jpeg"
    val sizeBytes: Long,
    val pageCount: Int,
    val createdAt: Long,                         // epoch millis
    val updatedAt: Long,
    val source: String,                          // "scan" | "link" | "import" | "convert"
    val isEncrypted: Boolean,
    val hasOcr: Boolean,
    val hasWatermark: Boolean,
    val thumbnailPath: String,                   // 私有目录下的 .jpg 缩略图
    val filePath: String,                        // 私有目录下的实际文件
    val ocrText: String? = null                  // FTS 索引用
)

@Entity(tableName = "tags", primaryKeys = ["documentId", "tag"])
data class DocumentTag(
    val documentId: String,
    val tag: String                              // 用 # 前缀方便搜索
)

@Entity(tableName = "folders", primaryKeys = ["documentId", "folder"])
data class DocumentFolder(
    val documentId: String,
    val folder: String
)

// FTS4 虚拟表（用于全文搜索）
@Entity(tableName = "documents_fts")
@Fts4(contentEntity = Document::class)
data class DocumentFts(
    val name: String,
    val ocrText: String?
)
```

## 6. 权限

| 权限 | 用途 | 是否必选 |
|------|------|:-------:|
| CAMERA | 拍照扫描 | ✅ 必选 |
| READ_MEDIA_IMAGES (API 33+) / READ_EXTERNAL_STORAGE (≤32) | 从相册导入 | 🟡 可选 |
| INTERNET | **不申请** | ❌ |
| WRITE_EXTERNAL_STORAGE | **不申请**（v0.1 不写公共目录） | ❌ |
| POST_NOTIFICATIONS | v0.1 不做 | ❌ |

> **INTERNET 权限在 v0.1 不申请** —— 这是"完全本地"的关键声明。如果未来要加 ML Kit 模型下载，**在设置页里让用户手动开关**，且 App 启动时不主动联网。

## 7. UI / 交互规范

- 8dp 网格、48dp 最小触控目标
- Material 3 + 暗黑模式（背景纯黑 #000）
- 中文优先，字号 14sp 起，主要内容 16sp
- 全部按钮加 contentDescription
- 扫描页快门按钮 ≥ 72dp
- 列表用 LazyColumn，缩略图用 Coil 异步加载
- 错误状态：Toast（短）/ Snackbar（带操作）

## 8. 验收标准（Acceptance Criteria）

### 8.1 功能验收

| 场景 | 验收 |
|------|------|
| 离线冷启动 | 飞行模式下首次启动，App 可正常打开所有页面 |
| 扫描 | A4 文档拍照 1 张，1 秒内裁出 4 边 + 透视矫正，导出 PDF 后在 Adobe Reader 打开正常 |
| OCR 离线 | 飞行模式下扫描含 200 字中文的 A4，OCR 完成后在 App 内能搜索"合同"命中 |
| 加密 | 加密后的 PDF 用第三方阅读器打开必须输入密码 |
| 全文搜索 | 1 万份文档库下，搜索关键词响应 < 500ms（模拟数据） |
| 链接 → PDF | 飞行模式下粘贴 https://example.com，单页静态页面 100% 还原 |
| 标注 | 高亮 / 涂鸦 / 手写签名在 App 内 / 第三方阅读器均可见 |
| 系统分享 | 通过系统分享发送到"文件管理"App 可正常收到 PDF |

### 8.2 性能验收

| 指标 | 目标 |
|------|------|
| 冷启动时间 | < 1.5s（中端机，Android 13） |
| 单页扫描到 PDF 输出 | < 2s（无 OCR） |
| 单页扫描到 PDF 输出（含 OCR） | < 5s |
| 100 页 PDF 阅读切换页面 | < 200ms |
| 1 万份文档列表滚动 | 60fps |
| APK 体积 | < 30MB（arm64） |

### 8.3 隐私 / 合规验收

- App 启动后**不主动发起任何网络请求**（用 Charles / mitmproxy 抓包验证）
- INTERNET 权限**未在 Manifest 中声明**
- 删除 App 后，私有目录**被系统一并清理**（Android 默认行为）
- 设置页有"**清除全部数据**"按钮，调用一次清空私有目录 + 数据库

### 8.4 法务验收

- 第三方库 License 自查（用 `./gradlew dependencies` + License Gradle Plugin）
- 不得包含 iText AGPL 静态链接
- 应用商店上架时**注明"本应用不收集任何数据"**

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| ML Kit Document Scanner 在国行 ROM 没有 Play 服务 | 边检 / 透视 / 阴影功能失效 | **必须用 OpenCV 做兜底**（v0.1 OpenCV 是主路径，ML Kit 是可选增强） |
| PdfBox-Android 性能弱于 iText | 大 PDF 处理慢 | v0.1 限制在 200 页以内；超限提示用户分批 |
| 链接 → PDF 对 SPA 渲染差 | 用户体验受损 | v0.1 明确**"仅保证静态页面"**；提供手动选区域截图 |
| 离线声明 vs 崩溃日志 | 真实设备总会偶发崩溃 | v0.1 崩溃日志写本地文件，v0.2 评估 Crashlytics 时单独走用户同意 |
| Material 3 暗黑模式与 PdfRenderer 兼容 | 部分 PDF 在暗黑模式显示问题 | 阅读器内允许用户切回浅色，记忆选择 |
